# Skycast

A responsive weather app that turns live forecast data into a simple, readable dashboard for current conditions and forecast-aware browsing.

## Highlights

- Live current weather powered by Open-Meteo APIs
- Search-driven location lookup with forecast exploration
- Hourly and seven-day forecast views
- Responsive layout built for desktop and mobile
- Condition-aware visual theming for a more atmospheric UI

## Tech Stack

- HTML
- CSS
- JavaScript
- Open-Meteo Weather API
- Open-Meteo Geocoding API

## Run Locally

Open `index.html` in a browser.

## Project Structure

- `index.html` - app layout and UI regions
- `styles.css` - responsive styling, theme system, and motion
- `script.js` - API integration, search behavior, and forecast rendering

## Why It Works Well For A Portfolio

Skycast shows API integration, stateful UI behavior, search interactions, responsive frontend work, and polished presentation in a lightweight project that is easy to review quickly.
